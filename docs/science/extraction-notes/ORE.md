# Extraction notes: deposit formation, coal, petroleum and placers

Written by the stage-1 extraction agent for this subsystem (2026-10-01/02) while it built the ledger. It holds the measured Earth-against-mod numbers found in the build log, the simplifications and game choices the code or documents state, and flags: admissions of unchecked values, contradictions between comments, code and documents, and things that looked wrong. **Nothing here is verified.** A line marked "suspicion" or "my arithmetic" is the extraction agent's own reading, to be checked in stage 2. See [claims.md](../claims.md).
Scope: where deposits form, geometry, clusters and children, coal, petroleum, placer channels, spawn and ore blocks. Sources are the build-log entries of STATUS.md and the notes inside the deposit_type JSON files. Nothing here was re-verified.

## Simplifications and game choices

- **Peat-to-coal.** There is no peat accumulation rate and no compaction ratio in the code; coal measures are the sediment laid down while the cell was coal-forming (favourability times deposition times time), split among seams. The peat-mire rule compares total net deposition (5-150 m/Myr) with a band, not a peat rate. The research note's 11:1 compaction is unused. Reason given: "Every number below is a design value" (facies.rs).
- **Coal definition.** One deposit is one minable seam field (decisions log 2026-09-29), an estimate, "NOT a USGS figure". Fields adjoin and stack (log 2026-09-29), sit in the sedimentary cover (log 2026-09-30), and eroded fields free their space (log 2026-09-30).
- **Coal rank** is read from the TTI of the column's richest-organic layer, with four placeholder bounds (3, 10, 75, 500) and no medium-volatile bituminous class; only TTI 75 has a (secondary) source.
- **Petroleum.** Oil only: generation from TTI 15 to 160 and above 80 degC; no gas window, no cracking, no preservation deadlines in the code (documented in petroleum.json only). Migration is a straight distance of at most 50 km from any kitchen cell; there are no carrier beds, spill or fill-and-spill logic (the file spill.rs concerns frame storage on disk, not hydrocarbons). Reservoir porosity and saturation are folded into one density, 0.13 t/m3. A trap is destroyed outright when erosion reaches it.
- **Heat.** Linear geotherm, heat flow over a uniform conductivity of 2.5 m/K, plus surface temperature; the temperature is that of the richest-organic layer.
- **MVT.** Brine flow is a window average (basin_brine and head drop within 600 km), not a flow solution; salinity is not modelled.
- **Time windows.** The BIF acme, the 2.02 Ga sediment-hosted Zn-Pb limit and land plants are clocks; on the recorded pipeline they are stand-ins 0, 1, 1 until the preset carries planet.atmosphere, so no date window is applied.
- **Size and position.** Bodies are enlarged by size_mult_h / size_mult_v (design choices) at 300 m x 20 m per block; ore density per block is a constant of the type, and grades never reach blocks (richness is a no-op in the world). Zones, aspects, dips, clustering are design values.
- **Placers.** Gold travels at most 5 km on a 4.8 km grid; the later bake moves each placer into the nearest baked river within 30 km as gravel bars, else a bench (Ben, 2026-10-01).
- **Background scatter** values are "initial, judged against the deposit renders"; impact types do not claim their products.
- **Synthetic planet** (synthetic.rs): "All numbers here are design values for a test planet, not measurements."

### Contradictions between comment, code, data and docs

- **Porphyry density.** geometry.rs doc and its test size the median porphyry at 2.6 t/m3 ("240 Mt / 2.6 t/m3 = 9.2e7 m3", a 452 m cube); porphyry_cu_mo_au.json uses ore_density_t_m3 2.7 (also used by supergene_cu_blanket.json). (ORE-057)
- **Coal data file out of date.** coal.json still carries tonnage 4.2 / 13 / 25 Mt and a note quoting the replaced 540 / 2,500 / 10,000 Mt, while coal_seam.json is 3,800 / 19,800 / 115,000 Mt; the STATUS 2026-09-29 USGS-mean-density entry says "coal's 30 stays a placeholder" (it is now 14 P50). (ORE-134)
- **Oil density.** OIL_T_M3 = 0.85 t/m3 (CDG charge), the barrel conversion 0.1364 t/bbl implies 0.858 t/m3, and ore_density 0.13 uses 0.85 (0.2 x 0.75 x 0.85 = 0.1275). About 1 % apart, but three statements of one number. (ORE-187, 188, 189)
- **MVT fluid temperature.** mvt_zn_pb.json says brines 75-200 degC (Leach et al. 2005; Garven 1985); regional.rs quotes Garven 1985 as 60-100 degC at Pine Point and Leach et al. 2005 as 90-200 degC, and its ramp is 50-100 degC. (ORE-003, 004)
- **Richness.** DepositParams.richness_mult is documented as scaling zone grades and each site's metal; the audit found zone grade is never read, so it changes no block. STATUS 2026-10-01: "the editor's 'Deposit richness' is a no-op in the world". (ORE-232)
- **Time windows documented but not applied.** fields.rs says sediment-hosted Zn-Pb only after 2.02 Ga, BIF acme 2.65-1.85 Ga; surface/fields.rs sets the clocks to 1, 1, 0 and inherited_bif to 0 for every recorded history, and surface/mod.rs passes land_plants: true always. So on a recorded history BIF cannot form (the audit: "none formed on either planet") and Zn-Pb and coal have no date limit. (ORE-014 to 020)
- **Oil window edges.** The code ends oil generation at TTI 160 (Waples), whereas the USGS reports in the same data file use 160 for the onset of thermogenic gas (PP 1698) and 180 for the base of the oil window (OFR 88-450-G), and TTI 10 rather than 15 for the onset. petroleum.json records this; the code does not choose between them. (ORE-160 to 162, 195, 196)
- **Placer transport range vs grid.** transport_km 5 against an L1 cell of 16 blocks x 300 m = 4.8 km (l1_r 16): a diagonal step is 6.8 km, longer than the range, so by my reading of placer_cell the walk ends at the source cell unless the first step is orthogonal, and can never take a second step; the final position is then set by river_reach_km 30 (placer_channels.rs), not by the transport range. (ORE-207, 209, 212)
- **Porphyry body size.** My arithmetic from the stated numbers: 240 Mt at 2.7 t/m3 in an ellipsoid of aspect 1 : 1.43 : 1 gives semi-axes of about 246 x 351 x 246 m, a footprint of about 0.19 km2 and a height of about 0.7 km; the cited basis says median ore area 0.6 km2 and hypogene ore 1-1.5 km tall (SIR 2010-5070-B), which at that aspect would hold about 5 times the tonnage. Suspicion, from the ledger's own numbers. (ORE-058)

### Suspicions (my reading, not verified against any source)

- **TTI to Ro.** petroleum.json quotes the KGS table as "TTI 1,500 gives Ro ~3.8 (upper TTI limit for wet gas)" while the same file puts wet gas at 0.80-2.0 % Ro; the 3.8 looks high for a wet-gas limit. Possibly a transcription slip. (ORE-198)
- **Coal rank bounds.** By log-linear interpolation of the file's own KGS values (TTI 160 gives 1.3 %, TTI 1,500 gives about 3.8 %), TTI 500 would be about 2.6 % Ro; anthracite is usually thought to begin near 2 % Ro (from memory, unverified). The anthracite bound at TTI 500 may be high. (ORE-155)
- **Coal as source rock.** surface/fields.rs gives coal 3 wt% TOC (black shale 5), but coal is mostly organic carbon (from memory, tens of weight per cent); the 3 is probably a stand-in so that a coal bed is a weaker source than black shale. Also the single burial temperature is that of the richest-TOC layer, so a coal seam under black shale takes the shale's temperature for its rank. (ORE-156, 170)
- **Peat-mire thresholds** (P/PET 1.2, 5 degC, slope 0.002, 5-150 m/Myr) have no source; the rate band is applied to total net deposition, not to peat. (ORE-108 to 112)
- **Circular 891 page references.** coal_seam.json cites the 1,800 m depth limit as "printed p. 24, Table 3 p. 14", and coal.json as "Table 3, printed p. 24 (PDF p. 31)"; the two files give different page numbers for the same table. (ORE-133)
- **Illinois coal area.** "about 95,000 km2" in the density derivation equals 36,800 mi2, which the same note lists as not verified; the "about 3 per 100,000 km2" depends on it. (ORE-123)
- **Placer gold density.** The ore density 0.08 per block with the pay streak in the lower half yields a median of 30-55 ore blocks per placer; Ben called it "pathetic" (decisions log 2026-10-01). Defaults were not changed; three options are pending (STATUS 2026-10-01).

### Units and consistency notes

- survivors versus sites: "counted" uses an assessment depth per type (coal 1,800 m, petroleum 10,000 m, default 1,000 m); the coal target 68.6 is for the 1,800 m rule while the placed sites include deeper survivors, so comparing sites with the density is not like for like.
- spacing: coal uses `min_separation_m 0` (adjoining) while Circular 891's nearest spatial rule (measured radius 0.4 km, indicated 1.2 km) is a reliability radius, not an aggregation rule; the data file says so.
- coal.json lists reliability radii and thickness cut-offs that no code reads (documentation only).
- spill.rs (in the assigned list) contains no scientific claim: it is the on-disk spill file for history frames. recorded.rs and spawn.rs contain only software/layout constants and the game rules in ORE-247, 248, 249.
