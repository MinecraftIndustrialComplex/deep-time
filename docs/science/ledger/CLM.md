Part of the claims ledger ([claims.md](../claims.md): how to read the columns and the status marks). Feature page: [climate.md](../climate.md). Extraction notes with flags: [extraction-notes/CLM.md](../extraction-notes/CLM.md).

By status after WP-14a and the ice branch (2026-10-02): `verified` 23, `cited-unverified` 33, `from-memory` 2, `calibrated` 15, `game-choice` 28, `uncited` 53. CLM-147 to CLM-162 came with the climate ice branch (build log 2026-10-02, "Climate ice branch"): read from the code, no source fetched, so a named source is `cited-unverified`; the flowing ice sheet itself is in GLA-067 to GLA-076.

Extracted from the code as it stood on 2026-10-01/02 by a stage-1 agent. Stage 2 package WP-14a (2026-10-02) checked the designed-not-coded rows against their sources, added CLM-163 to CLM-166 (CLM-147 to CLM-162 are taken by the unmerged ice branch), and checked eleven coded rows the design carries over (their status says so); the other coded rows are unchecked and wait for WP-14b. Paths are relative to the repository root; line numbers are left out on purpose.

Scope: `crates/deeptime-core/src/climate/{ebm,insolation,orbit,carbon,clock,ice,glaciers,params}.rs` (the flowing sheet, `sheet.rs`, is in GLA), the physical constants in `climate/mod.rs`, `PlanetParams` in `crates/deeptime-core/src/params.rs`, and the `climate` block of `crates/deeptime-core/presets/earthlike_quick_16k.json`. Every status of coded rows carries `, pending-rewrite` (the banded climate is to be replaced by the per-cell model of `docs/design/p1-26-per-cell-climate.md`).

Preset check: every key of the `climate` block of `earthlike_quick_16k.json` equals the Rust `ClimateParams::default()` value (compared key by key for all keys in this ledger's scope). So a row's value is both the Rust default and the preset value unless a row says otherwise. `PlanetParams` has no Rust `Default` (all five physical fields are required keys); the preset gives the values.

Designed-not-coded rows (last group) are NOT code today: their status has no `pending-rewrite` suffix because they are the replacement, not the code being replaced.

Abbreviations: ppm = parts per million CO2; EBM = energy-balance model; ELA = equilibrium-line altitude (the height above which snow survives the summer); OLR = outgoing longwave radiation; ASR = absorbed shortwave radiation.
