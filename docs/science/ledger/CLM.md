Scope: `crates/deeptime-core/src/climate/{ebm,insolation,orbit,carbon,clock,ice,glaciers,params}.rs` and, since P1-26, `{coarse,ebm2d,ocean2d,moisture,percell,co2}.rs` with `co2_table.rs` (the flowing sheet, `sheet.rs`, is in GLA), the physical constants in `climate/mod.rs`, `PlanetParams` in `crates/deeptime-core/src/params.rs`, and the `climate` block of `crates/deeptime-core/presets/earthlike_quick_16k.json`. Every status of the banded-climate rows carries `, pending-rewrite` (the banded climate was replaced as the default by the per-cell model of `docs/design/p1-26-per-cell-climate.md` in P1-26; the banded model stays as `climate.model = banded`); rows rewritten for the per-cell model do not carry it.

Preset check: every key of the `climate` block of `earthlike_quick_16k.json` equals the Rust `ClimateParams::default()` value (compared key by key for all keys in this ledger's scope). So a row's value is both the Rust default and the preset value unless a row says otherwise. `PlanetParams` has no Rust `Default` (all five physical fields are required keys); the preset gives the values.

The per-cell group (CLM-119 to CLM-146, CLM-163 to CLM-166, CLM-167 to CLM-179) is the replacement, so its status has no `pending-rewrite` suffix. CLM-126 is the one row still not built (`not-yet-coded`).

Abbreviations: ppm = parts per million CO2; EBM = energy-balance model; ELA = equilibrium-line altitude (the height above which snow survives the summer); OLR = outgoing longwave radiation; ASR = absorbed shortwave radiation.
