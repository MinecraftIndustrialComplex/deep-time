# Ledger RLC: Realism checks, Earth's range for V1 item 1's measures

Part of the claims ledger ([claims.md](../claims.md): how to read the columns and the status marks). Feature page: [realism-checks.md](../realism-checks.md).

Rows: 31. By status: see the table in claims.md (counted by tools/review/claims_counts.py). Written 2026-10-23 by a docs and sourcing task (Sonnet 5.5): nothing here is code. A row is either a rule of the checks, an Earth figure with the source it was read in, or a proposed band. No ids were taken near other lanes: the ids go in blocks by measure (001 to 009 the method, 010s land share, 020s largest landmass, 030s continental crust under the sea, 040s land above 2 km, 050s coast with high ground, 060s ice, 070s collisions), with gaps left for rows a later task adds.

W = . Paths relative to W. "Where" names the file that computes or states the measure; the proposed bands change no file (tools/review/pool/measures.json is untouched: the coordinator decides). `verified` here means the value was read in a source fetched on 2026-10-23 and the row says which; the project's own arithmetic on read values is named as such. The PaleoDEM and relief figures are the project's own computation on fetched data (tools/review/earth-paleodem.py), marked `cited-unverified` as HYP-035 is. Wikipedia pages are read as tertiary sources and said to be.
