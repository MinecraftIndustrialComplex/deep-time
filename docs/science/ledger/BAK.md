# Ledger BAK: The bake

Part of the claims ledger ([claims.md](../claims.md): how to read the columns and the status marks). Feature page: [world-scale-and-bake.md](../world-scale-and-bake.md). Extraction notes with flags: [extraction-notes/SCL.md](../extraction-notes/SCL.md).

Rows: 42. By status: `calibrated` 1, `game-choice` 36, `uncited` 5.

Extracted from the code as it stood on 2026-10-01/02 by a stage-1 agent. Nothing here has been checked against its source. Paths are relative to the repository root; line numbers are left out on purpose.

Rust paths are under `crates/deeptime-core/src/`. "Decisions file" is `docs/deeptime-design-decisions.md`. The bake turns a finished run into the block-space layers the game reads (build log 2026-09-29 P1-08 bake, world data 0.1 and parity). Only physical or physics-standing-in-for-game claims are rows; buffer sizes, tile sizes, file formats, salts and debug colours are skipped. `bake/ice.rs`, `bake/water.rs`, `bake/climate.rs`, `bake/biomes.rs`, `crates/deeptime-core/src/bake/strata.rs` (beyond the build-limit count and the top raise) and `bake/placement.rs` (the Koppen class placement table, not spawn) belong to other ledgers.
